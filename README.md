# 观音·祈福屏保 / Guanyin Blessing Screensaver

一款 Windows 桌面屏保应用：观音圣像端坐莲台，佛号轻诵，为您与家人带来片刻安宁。

A Windows desktop screensaver: a serene Guanyin (Avalokiteshvara) in meditation with gentle Buddhist chanting, bringing a moment of peace to you and your family.

## 功能 Features

- **观音圣像** 全屏/悬浮小窗呈现，画风庄严祥和
- **佛号诵祷** 46 秒循环音频，可开关，锁屏后可延续
- **悬浮小窗** 可总在最上层，随时祈福
- **微软商店版** 1 天免费试用，到期后可在应用内直达商店购买

A serene Guanyin image · 46s looping chant (toggleable) · always-on-top mini window · 1-day free trial on Microsoft Store.
